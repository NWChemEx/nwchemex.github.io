An idiom is a recurring, language-level solution to a common programming
problem. Idioms are smaller in scope than design patterns: they usually
describe how to structure a single class or function rather than how several
classes interact. NWChemEx code uses a number of idioms. The pages in this
section give a reference explanation of each one, so design documentation can
link to them instead of re-explaining them. Each page covers:

- what the idiom is,
- why NWChemEx uses it,
- an example in C++ (and Python, when applicable), and
- a reference for further reading.
